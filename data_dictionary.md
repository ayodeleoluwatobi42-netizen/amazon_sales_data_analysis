# 📖 Data Dictionary

This document describes the columns contained in the Amazon e-commerce sales dataset and their purpose in the analysis.

| Column | Description |
|---|---|
| `index` | Unique row identifier from the original dataset |
| `Order ID` | Unique identifier assigned to an order |
| `Date` | Date the order was placed |
| `Status` | Overall status of the order |
| `Fulfilment` | Method used to fulfil the order |
| `Sales Channel` | Sales channel through which the order was placed |
| `ship-service-level` | Shipping service level selected for the order |
| `Style` | Product style identifier |
| `SKU` | Stock Keeping Unit used to identify the product |
| `Category` | Product category |
| `Size` | Size of the product |
| `ASIN` | Amazon Standard Identification Number |
| `Courier Status` | Status of the order shipment |
| `Qty` | Quantity of units ordered |
| `currency` | Currency associated with the transaction |
| `Amount` | Sales amount associated with the order |
| `ship-city` | City where the order was shipped |
| `ship-state` | State where the order was shipped |
| `ship-postal-code` | Postal code of the shipping location |
| `ship-country` | Country where the order was shipped |
| `promotion-ids` | Promotion or promotional campaign associated with the order |
| `B2B` | Indicates whether the order was a business-to-business transaction |
| `fulfilled-by` | Indicates the party responsible for fulfilling the order |
| `Unnamed: 22` | Unused/empty field present in the original dataset |
